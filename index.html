PhotonRelay engineering lab

What survives a noisy channel?

Exercise the same fountain encoder and decoder used by Send and Receive, with seeded frame loss, duplicates and shuffled delivery. No camera or network. This is a software simulation, not a physical throughput benchmark.

64 KiB payload · 512-byte blocks · 16-frame shuffle windows · bounded to 1,536 emitted frames.

Share this app

Scan this with another device's camera, or send it the link.

A network path is not required between the devices. The bytes travel as light. Files are not encrypted, so anything on the sending screen is readable by any camera pointed at it.
